# 安路赛题一｜从当前版本到作品提交的执行规划

> 基准：2026-10-07（北京时间）。平台：AC601 + AC201 / ES8388 + EG4S20BG256。规划 v1.0。
> 本文是尚未执行的计划，不改变当前开发状态。日期是目标窗口，工时是AI辅助开发下的人工估算，不是完成承诺。

## 1. 起点与交付目标

依据最新《当前状态.md》和10月7日日志：整板、本机重编译、TF四图与按键、HDMI内部测试音、指定TEST.WAV与图片并发的基本场景已收到用户正常上板反馈。持续运行时长和采样率实测未记录。当前并非只完成色条，也并非已经完成通用音乐播放器。[F01/F02]

当前WAV仍依赖绝对15124扇区、768000数据字节、标准44字节头、48kHz/16位单声道及连续物理扇区；FAT32目录/簇链、通用PCM WAV解析、Flash自启动尚未完成。[F01/F02]

主线目标为全部基础＋文件化播放器＋五项扩展（动态OSD、转场、缩放、实时参数调节与OSD、真实音频可视化）。先做波形、最近邻和一种连续转场；FFT、双线性、双图交叉淡化作为可选质量增强。720p60先过独立闸门再集成，失败继续640×480；1080p不作为提交前置。[F03/F04/P]

指南第14—15页写扩展不强制，解析PPT写至少完成1项；本规划不自行裁定文档效力，T02需保留口径依据。全部五项是本计划目标，不是五项全部必做的官方说法。[F03/F04]

第三方板卡认可沿用最新记录，不再回退到旧“只能HX4S20C”的限制；归档认可凭据即可。不得引入额外处理器或HDMI驱动板绕过要求；最终保留功能必须在一个固化设计内操作，不能多次加载镜像拼功能。[F01/F03/F04/F05]

## 2. 截止与工作量

公开高校通知列作品提交截止为 **2026-11-04 18:00**。内部目标 **11/02 18:00前正式提交并回读确认**；11/03—11/04仅处理补交/格式/传输问题。此次官网首页抓取超时，未登录队长后台；模板、视频时长/大小、命名、源码/bit上传要求须在T02/T52核定。不得将本计划的建议当作后台正式要求。[W01/W02/P]

共57项任务，其中主线53项、123人工小时；另有4项P2共15小时。主线加25%缓冲为153.75小时。默认三人每人每周15小时是可编辑建议预算；不能用几次快速成功推定其余任务都能一次通过。编译无人值守和长稳等待不计人工时，但仍占日历窗口。[P]

建议分工：A统筹集成、Agent、构建与版本；B负责图像算法、缓存/资源预算与测试；C负责音频验证、实测证据、报告视频和提交材料。A/C主线负载较紧，P2启用时应由B分担测试/素材/报告工作。每次仅由集成人合入顶层、约束和共享接口。[P]

## 5. 每项任务的具体动作与完成标准

### [ ] T01 封存最新可回退基线

**P0 · S0 接续与冻结 · A负责 · 10/07—10/07 · 估算0.75人工小时**

动作：封存 tf_wav_hdmi 的源码、构建脚本、约束、IP、位流、卡布局校验和素材哈希；保留其他 bringup 成功版。

验收：能定位最新 WAV 位流及 SHA256；源码、卡和位流一一对应；旧成功版本未被覆盖。

产物：baseline/清单、Git 标签、bitstream_info.json。

受阻/回退：现有 WAV 绑定物理扇区；没有卡布局记录的副本不能当作可复现基线。

前置：无。依据：[F01/F02]。

备注：这是后续封存任务，不把过去已经跑通的功能重复记为待开发。

### [ ] T02 核对提交规则与资格留证

**P0 · S0 接续与冻结 · C负责 · 10/07—10/08 · 估算1.25人工小时**

动作：查队长后台/最新群通知，记录截止时刻、报告模板、视频格式/时长/大小、命名和源码要求；归档第三方板卡认可记录。

验收：规则确认表注明版本日期；未知项有负责人和再核对日期；不重新质疑已确认的 AC601+AC201 资格。

产物：submission_rules.md、后台截图、主办方认可留证。

受阻/回退：公开高校通知仅用于排期；门户最新要求与材料冲突时提交主办方确认，不自行裁定。

前置：无。依据：[F01/F03/F04/W01/W02]。

### [ ] T03 冻结作品场景和首版接口

**P0 · S0 接续与冻结 · 全员负责 · 10/07—10/08 · 估算1.5人工小时**

动作：拟定离线音画展陈/公告播放器场景；冻结支持格式、模块边界、按键/拨码复用、错误提示与各阶段接口。

验收：每项功能有可演示场景；明确只读 FAT32、受限 BMP/PCM WAV；未把 MP3/JPEG/外设扩展混入主线。

产物：scope.md、interface_contract.md、操作映射表。

受阻/回退：先把一套场景做好；按键数量以 AC201 实物为准，不照抄 HX4S20C。

前置：T01。依据：[F01/F03/F04/P]。

### [ ] T04 补齐当前基线实测记录

**P0 · S0 接续与冻结 · C负责 · 10/07—10/08 · 估算1人工小时**

动作：同一稳定电源和线材运行最新 WAV+四图版本；记录显示器、电源铭牌、板卡/卡信息、连续运行时间和切图听音。

验收：建议连续 30 分钟、完整手动循环和自动轮播；实测现象与用户口述分开，异常有时间点。

产物：baseline_test.md、短实拍、设备照片。

受阻/回退：持续时长原来未记录；本任务完成前不要写成已经通过长期稳定性。

前置：T01。依据：[F01/F02/P]。

### [ ] T05 整机资源/帧缓存预算

**P0 · S1 资源与工程化 · B负责 · 10/08—10/09 · 估算1.5人工小时**

动作：读取整机 LUT/FF/ERAM/乘法器/PLL 占用；列实际像素存储位宽、前后帧/行缓存/音频 FIFO 地址；估算读写并发需求。

验收：形成基线与五项扩展预算；不把约5470 LUT的 WAV模块占用当作整机占用；不以位流大小估算资源。

产物：resource_budget.csv、memory_map.md、Routed资源报告。

受阻/回退：720p/缩放/双帧转场先过预算；资源超限先减小缓存或优化映射，不直接加板。

前置：T01。依据：[F02/F07/P]。

### [ ] T06 优化 WAV FIFO 的 RAM 映射

**P0 · S1 资源与工程化 · A负责 · 10/09—10/11 · 估算4人工小时**

动作：把当前分布式 RAM FIFO 改为显式/可确认的 ERAM实现；保留握手语义并复测满空、同时读写、预取及 EOF。

验收：综合网表确认存储实现；比较整机优化前后资源和 Routed时序；样本逐个一致，切图不产生新欠载。

产物：FIFO RTL/IP参数、TB、资源对比、成功位流。

受阻/回退：不是盲目换 IP；新版本未通过时回退原 FIFO，并将剩余资源据实纳入预算。

前置：T05。依据：[F02/F08/P]。

### [ ] T07 审计时钟/CDC/约束疑点

**P0 · S1 资源与工程化 · A负责 · 10/09—10/12 · 估算3人工小时**

动作：核对实际 PLL 生成频率、相关时钟关系、复位与 CDC；追查加密 SDRAM clk 告警，补接口时序依据及未覆盖路径说明。

验收：不以 exclusive/全局 false_path 隐去有效路径；每条保留告警有证据、影响范围和验证方案。

产物：clock_plan.md、CDC审查、SDC差异、告警台账。

受阻/回退：不能为追求覆盖率伪造 I/O 延迟；无法解释的关键问题在 T39/T40前关闭或明确限制并升级求助。

前置：T05。依据：[F01/F02/F09/P]。

### [ ] T08 720p60 可行性闸门 G1

**P1 · S1 资源与工程化 · B负责 · 10/09—10/11 · 估算3人工小时**

动作：在独立分支核对目标视频时序、PLL与发送链路；先测试图，再实际帧缓存读图+音频；测读缓冲最低水位与时序。

验收：记录实际输出分辨率/刷新率与 Routed报告，帧缓存路径不欠载；明确决定720p主线或暂留640×480。

产物：G1_resolution.md、候选位流、显示器输入信息实拍。

受阻/回退：测试图能出图不代表整机可用；未通过则后续功能继续在640×480实现，不等高清。

前置：T05。依据：[F01/F06/P]。

备注：720p60为拟定提升目标；当前已测媒体链路不是720p。

### [ ] T09 统一数据接口与故障计数

**P0 · S1 资源与工程化 · A负责 · 10/09—10/10 · 估算2人工小时**

动作：固定像素流/PCM/文件读取/控制事件接口；添加欠载、读卡错误、超时、帧提交次数和FIFO最低水位等观测点。

验收：计数可从 LED/OSD或现有调试手段读取；清零/复位定义明确；各开发分支按同一接口接入。

产物：接口头文件、状态寄存器表、观测说明。

受阻/回退：调试信号和功能逻辑一起算资源；不为了记录状态额外引入处理器。

前置：T03、T05。依据：[F01/F02/F04/P]。

### [ ] T10 实现只读 FAT32 挂载

**P1 · S2 文件化播放 · A负责 · 10/11—10/13 · 估算4人工小时**

验收：能校验分区布局并给出 FAT/数据区位置；非法参数有上界检查和明确错误；不改 TF 原始数据。

产物：fat32_mount模块、TB、卡镜像测试记录。

受阻/回退：首版不做格式化、写文件或 exFAT；保留固定素材读取成功版本。

前置：T06、T09。依据：[F01/F02/P]。

## 7. 测试用例

测试状态初始全部未执行。30分钟基线、2小时交互回归、8小时轮播长稳、10次冷启动均为建议值，不是赛题一官方量化门槛。

- [ ] **TC01｜基线｜四图与音频回归**：前提=当前成功卡+WAV基线；操作=手动切四图；开/关轮播；播放TEST.WAV；预期=图序/声音与已测基线一致，记录连续30分钟目标；方法=上板+实拍；关联=T04；级别=P0。
- [ ] **TC02｜按键｜消抖及忙时快速操作**：前提=最终操作映射；操作=单击/长按/连续切换/加载中按键；预期=不连跳、不死锁；忙时策略与规格一致；方法=TB+上板；关联=T17/T24/T37；级别=P0。
