# C42：SDRAM 100MHz 上板指南

用 BitWriter 的 `PROGRAM_SRAM` 加载 `video42_sdram100.bit`，确认数码管版本为 **00C11342**。沿用当前 TF 卡素材、原 HDMI 接法和独立 5V USB 电源适配器，AL-LINK 接电脑。

本轮主要变化是 SDRAM 时钟设为100MHz；TF数据时钟25MHz、SD逻辑50MHz，图片640×480、视频640×480/15fps保持现用素材规格。最终 routed STA 的 setup/hold WNS 为 +0.285ns / +0.037ns，TNS 均为0；资源为 Slice 8884/9800（90.65%，C41多87）、BRAM 62、DSP 26。先等待 BitWriter 明确显示下载完成，再操作按键。

离线证据包含 PLL phase8 最终运行 `units_20261027_222447`（PASS），以及最终 routed memory-data 长突发4352字、短突发460字逐字检查（PASS），覆盖 SDRAM 数据路径与读写仲裁。仿真使用功能模型且未带 SDF。C41 整机播放已由用户通过；C42 本轮整机播放、板卡 SDRAM 行为、连续播放与冷启动待板测。离线检查汇总和最终位流/路由哈希绑定通过后再进行本指南的上板验收。

## 按键

实体按键标记与 RTL 名称对应为：板上 **KEY0 = RTL `key1`（F7）**，板上 **KEY1 = RTL `key2`（E7）**。

| 操作 | 图片模式 | 视频模式 |
| --- | --- | --- |
| KEY0 短按（RTL `key1`） | 下一张图片 | 当前视频从头播放 |
| KEY1 短按（RTL `key2`） | 自动播放开/关 | 暂停/继续 |
| KEY1 单独长按约1.5秒（RTL `key2`） | 原声/内置音阶切换 | 原声/内置音阶切换 |
| KEY0+KEY1 短按 | 冻结/恢复 HDMI 音频波形显示 | 冻结/恢复 HDMI 音频波形显示 |
| KEY0+KEY1 同时长按约1.5秒后松开 | 切换到视频模式 | 切换到图片模式 |

## 先做功能检查

1. 加载后等10秒，检查首张图片、原声和频谱；用 KEY0 连续切图10次，观察动画和颜色。
2. 单独长按 KEY1 约1.5秒切到内置音阶听一遍，再长按 KEY1 恢复原声，确认声音清楚、连续。
3. KEY0+KEY1 短按冻结 HDMI 音频波形显示，再短按恢复更新。切到视频，检查播放、KEY1暂停/继续、KEY0从头播放。
4. 做5次图片→视频→图片往返，其中两次在视频只播1～2秒时切回。KEY0+KEY1 同时长按约1.5秒后松开切换模式。
5. 记录数码管三页：`00C11342`版本；`C000xxxx`已校验TF扇区数；`E000xxxx`CRC不一致数。C页随读取增加，达到FFFF后保持；E页期望为0。

## 再做稳定性检查

图片静置5分钟后切图；视频连续播放3分钟。观察画面、声音和频谱是否稳定。

做3次冷启动：每次等烧录结束，断板卡电源约10秒，重新上电，再用 PROGRAM_SRAM 加载 C42，确认版本后重复首次出图/出声检查。当前使用 SRAM 配置，断电后需重新加载该位流。

## 异常与回退

记录异常发生的模式、按键动作、屏幕与声音表现、C/E页。可录一轮数码管及屏幕，保留本地录像路径。

用 `rollback/video41_refresh.bit` 回载已正常的C41，确认 `00C11341`，同卡、同线、同供电重复异常动作。包内C41与已确认正常位流逐字节一致。
