# P4 原生 LVDS 到 HDMI 草案独立审查

日期：2026-10-27  
范围：只读核对 `P4到HDMI无源转接评估_20261027.md`、匹配 AC201（2026-08-14；ES8388 旧版图第8页对应接口）、AC601-EG4S20 核心板图、C39 的 `pin.adc`、DS301 及既有电气证据。未改生产约束/位流，未运行 TD/EDA，未接线或测试硬件。当前原理级结果，不代表转接板或显示实测。

## 结论与 FIX FIRST

本轮没有确认到草案 P4 针号表的电源/地硬冲突。初稿将 PDF 文字提取结果按文本次序对应到双列针号，造成疑似跨列错配；对照现有针号裁图后，根代理目视确认左25=GPIO2_21、右26=VDD3.3、左29=GND、右30=VCC5.0，与初稿部分读法相矛盾。原始图纸为 `E:/QQ CACHE/Download/安路资料/赛题1_工作资料/03_小梅哥硬件与例程/AC201_EG4S20_底板_20260814.pdf` 第8页，截图为 `E:/VSCODE-project/FPGA-ANLU/development/video39_work/electrical_review/P4_verified_crop.png`。当前审查以截图的针脚坐标和导线端点为准，文字提取排序不作为双列针号证据。完整八线球位到P4针脚闭环仍需逐网核验后再冻结。

按严重度排序：

1. **FIX FIRST｜完整映射链仍待逐网闭环。** 已直接核实的 P4 针脚包括左25=GPIO2_21、右26=VDD3.3、左29=GND、右30=VCC5.0（依据上述第8页截图，由根代理目视确认）。C39 ADC定位的是差分正端，AC601图可确认球位P/N，AC201 P4图可见连接器针号/网络；本轮尚未对所有P4行逐根追线并建立球位→板间触点→P4网名→物理针号的坐标闭环。失效场景为双列位置或P/N任一行接错，导致无显示、lane互换、或供电/地接错。**最小修正：以网表或逐页图纸导线核对形成八线映射表，再按实物pin1标记复核。**
2. **已核对的信号端点与仍缺链路。** C39 `pin.adc` 的正端定位与 AC601 核心板球位表相符：K11/J11=`IO_L4P/N`，L14/M14=`IO_L6P/N`，K15/M15=`IO_L7P/N`，H13/J13=`IO_L9P/N`。HDMI Type-A P/N脚号草案也符合连接器定义：Clock 10/12，D0 7/9，D1 4/6，D2 1/3。P4每根信号至上述球位的完整网络链尚未逐网完成坐标核对。失效场景为双列针号、P/N或lane映射错位；**最小修正：用匹配网表/逐页导线证据完成 FPGA球位→AC601板间触点→AC201网络→P4物理针号映射，并核实实物pin1方向。**


3. **阻断｜P4.30可供HDMI.18的电流与保护能力未证实。** AC201第5页电源图显示 VCC5.0 由电源输入/USB VBUS选择网络供电并馈入板上电源电路；P4第8页把 P4.30标作 VCC5.0。当前证据未给出 VCC5.0可用电流余量、P4走线/连接器额定值或独立过流保护。HDMI Type-A pin18是源端+5V；将共享5V直接外送会把未知负载引入底板电源网。**最小修正：在设计冻结前确认上游限流/保险和连接器额定值；必要时在转接侧设置合适限流保护，实测空载/负载电压及限流行为。**不得由“网名为VCC5.0”推断满足 HDMI 供电规范。

4. **阻断互通性｜HPD/DDC/CEC未闭合。** HDMI Type-A pin19=HPD、15=SCL、16=SDA、13=CEC、18=+5V、17=GND；草案不接这些控制/检测脚。固定时序只减少 EDID 模式选择需求；终端是否稳定识别并保持输入仍取决于接收器实现，需用目标屏验证。无 HPD/DDC 时某些接收器可能仍锁定固定 TMDS，兼容性取决于终端实现。**最小修正：明确本阶段目标终端与仅固定时序的启动行为；若要求通用输入，按 HDMI 源端电平/上拉/供电/HPD 时序实现并做终端验证。**现有图纸显示 AC201 原 J4 HDMI 的 HPD/DDC不接 FPGA；该原生支路不构成新接口控制链的验证证据。

5. **设计冻结项｜机械/布线与器件参数未定。** 实物P4针1方向、18×2 2.54mm座的可插配连接器型号/性别、板厚/支撑、插板朝向、与HDMI Type-A母座或线缆的受力、壳体/屏蔽接地均未从原理图确认。草案也未给出AC耦合电容具体封装/介质/高频参数、ESD器件电容或阻抗/长度约束的数值预算。**最小修正：落板前对实物量针距/针1和机械配合，定义连接器料号与固定方式；复核高速回流路径、阻抗与ESD器件加载。**

## 电气拓扑判断与适用边界

- 无源耦合原理存在参考先例：本地 ADI CN0571 第6页（已归档于 `development/video39_work/electrical_review/browser_followup_1605/ADI_CN0571.pdf`）描述 LVDS 经串联 10–100 nF 电容耦合到 CML/HDMI 接收输入，由接收端每线50Ω端接建立偏置，并说明短连线的特定变体可省输出缓冲。它支持“有条件可尝试”的拓扑，不构成 EG4S20、具体接收芯片、连接器/线长组合的兼容认证。
- 源端 LVDS 的幅度指标以 DS301/DS300所定义的负载条件为准；既有证据记录 DS300 表3-1-15 的标准档 VOD 为150/250/350mV(min/typ/max)，大摆幅档450/480/550mV，条件含RT=100Ω。DS301 电气摘录在本轮未能独立复核全部 LVDS 数值，故不将 DS300 表直接声称为DS301数据。C39当前约束仍是 LVDS33 默认配置；构建报告/LED仅表明配置和帧计数活动；输出摆幅/共模仍须实测。
- HDMI接收端若已提供每路约50Ω到其偏置电源，两个端接共同形成差分负载；AC耦合会隔离收发端共模。此条件成立时不应再并联一个100Ω跨线电阻，否则负载可能降得过低。若目标接收端端接结构、输入共模范围或板级终端未知，先查器件资料/测量；“不额外放100Ω”当前属于条件性建议，非已验证结论。
- 100nF 是草案的初选值。其低频基线恢复/协议空白段行为及与输入阻抗的时间常数需依实际TMDS接收端确认；本轮无该接收芯片型号、接收板图或波形证据。

## 已核对正确项与验证状态

- C39原生 LVDS33约束位置与AC601球位对应：Clock K11/J11，D0 L14/M14，D1 K15/M15，D2 H13/J13；命名正端对应 P 球位。P4是底板通用显示扩展座，不等同HDMI J4。
- HDMI Type-A TMDS主链脚位（差分对顺序、+/-号）符合该连接器引脚定义；地脚2/5/8/11/17可作信号回流地，连接器屏蔽壳另需明确机壳/地策略。
- 用户反馈的C39状态为PLL锁定和帧活动指标；P4转接尚未制作。本审查不推断已显示、已兼容或电气裕量已足。
- 已逐项查看草案、C39 `pin.adc`、AC601图第2页、AC201匹配底板图第5/6/8页、P4针号裁图、TD ADC属性调查和CN0571本地PDF。无TD/EDA、无网络消息、无购物/实物动作、无生产文件改动。
