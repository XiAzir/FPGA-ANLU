# C11330 探针精简候选

沿用当前 TF 卡素材、HDMI 和外接5V USB适配器供电。加载 `video30_probe_prune.bit`，数码管固定显示 **00C11330**。

本版删除HDMI音频包监视、PCM CRC、帧内存观察、SD被动CRC统计、等待/欠载历史计数、诊断快照及轮换页面；将音频源选择和图像有效门控保留为播放路径。内置音阶、频谱/波形、图片/视频、亮度/对比度和按键操作沿用。

LED改为直接表示当前状态，低电平点亮：

| 灯 | 点亮含义 |
|---|---|
| D3 | 视频模式 |
| D2 | 内置音阶 |
| D1 | 已有有效显示帧 |
| D0 | 文件系统挂载完成 |

图片原声正常时通常D1/D0亮；视频原声通常D3/D1/D0亮；切内置音阶时D2亮。数码管保留版本识别，原来的16页诊断已删除。

## 上板核对

1. 默认图片模式：核对图片轮切、原声清晰、频谱跳动；单键操作及亮度/对比度按原方式验证。
2. 切内置do/re/mi，再恢复原声，核对两种音源及频谱/波形。
3. 切视频：核对画面、原声、启停、短KEY0从头播放。
4. 图片↔视频往返5次，包含视频只播1～2秒就返回；视频KEY0重播3次。

正常时文字反馈即可。若出现黑屏、杂音或按键异常，先保留现场录屏幕、声音及版本；再用同条件C29回退对照。随包 `video29_media_flow_rollback.bit` 与已实测C29字节相同，诊断页定义见原C29说明包。

## 离线证据

精确源消融、真实控制位反相负控、260周期源门控对照通过；重启回归完成4次模式切换＋2次视频重播，10875个PCM样本黄金一致，4个完整640×480 RGB帧/JPEG输入CRC吻合，外置SPI卡模型协议错误0。

最终资源与时序、D0/C29→D1→D2/C30同策略综合数据见包内凭据。离线模型采用名义PLL和SDRAM应用接口；C30实板结果另行记录。C29已通过版本及原包继续保留。
