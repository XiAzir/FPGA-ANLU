# C11301 波形清晰度候选规格

基于C11206已验证268项快照隔离开发。输出仍640×480；PCM观察端不影响HDMI音频消费、WAV读取或内部音阶。候选未上板；C11206继续为成功基线。

- 横向512列、每列2个PCM样本，窗口共1024样本（48kHz名义21.333ms），原版128列每列8样本。图形仍x=64..575、y=356..412。
- 两个完整捕获bank，各512个18位{max9,min9}；每个code为四分之一像素，`clip(floor(PCM16/64)+112,0,224)`。PCM16来自HDMI24位输入[23:8]。显示增益/中心/范围仍与原版相同；物理纵向仍57行，增加的是亚像素定位，不能称为显示器分辨率提高。
- 每列保留两样本极值，以当前列中点与前一列中点连接，合并当前极值范围。x=64无前列连接，每行重新清除邻列缓存。同步BRAM预取必须与当前坐标对齐。
- 在区间内全亮青色，区间外距边界1/2/3个四分之一像素分别3/4、1/2、1/4亮度，超过则背景。线条连通与边缘过渡减少4像素宽阶梯；不是音频滤波或FFT。
- bank只在VS上升时交换，活动帧不写front。冻结/恢复、超时、切音源与VS同时事件策略沿用原模块；切音源清除冻结并使旧front在VS失效。
- 硬资源预算：trace存储18432bit，预期2个BRAM9K（须以TD真实映射核对），目标总BRAM<=32、DSP保持8；不添加全帧缓存。HDMI PHY/PLL/引脚/SDC/WAV/缩放/控制字节不改（top仅build ID）。
- 验证：独立整数gold检查512列极值/连接/4档边缘及左右边界；VS无撕裂、HOLD/恢复、音源切换、stale、真实像素扫描；相关控制/叠加模型；正式TD原约束setup/hold/TNS非负后才bitgen。实板音画/清晰度等待用户验证。

动态双线按原已知项保留，其唯一成因尚未证实；不得从模型或清晰度变动宣称根因修复。
