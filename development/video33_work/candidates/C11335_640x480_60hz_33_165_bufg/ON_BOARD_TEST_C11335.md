# C11335 上板测试

位流：[AC201_C11335_640x480_60hz_33_165_bufg.bit](build/manual/AC201_C11335_640x480_60hz_33_165_bufg.bit)，版本码`00C11335`。该候选保持165MHz串行链路与全局时钟路径，改成640×480、计算刷新率60Hz自定义时序，用于比较接收端能否锁定低分辨率/常见帧率一档。

1. 与C11336分开加载；固定同一显示器输入口、HDMI线、5V供电和板卡接线。AL-LINK接电脑，板卡由当前独立USB 5V适配器供电。
2. BitWriter确认器件`EG4S20BG256`，选择`PROGRAM_SRAM`，写入本页位流，等待完成。
3. 启动约30ms后观察背光、无信号提示和八色彩条；记录D0–D3常亮/闪烁、首次出图与短时稳定情况。能查看显示模式时记录菜单值。
4. 若无信号，记录显示器文字/背光及D0–D3状态。C11335与C11336使用同一165MHz串行链路及BUFG，因此两者现场结果可用于判断模式/刷新接受情况；保留不同步宽和分辨率等已说明的扫描差异。
5. BitWriter确认结束后再切换位流或关闭电源。此过程只写SRAM，不做Flash固化。

参考回退位流：[C32已确认基线](../../../player_video32_read_return/build/manual/AC201_player_video32_read_return.bit)。
