# C11336 上板测试

位流使用 [AC201_C11336_1080p15_serial_bufg.bit](build/manual/AC201_C11336_1080p15_serial_bufg.bit)，版本码`00C11336`。测试目标是判断给165MHz串行时钟补回C32使用的全局缓冲后，自定义1080p15彩条能否被当前显示器识别。

1. 保持当前已验证的HDMI线、输入端口、板卡5V供电和接线不变。AL-LINK连接电脑，板卡继续使用原独立USB 5V适配器供电。
2. 打开BitWriter，确认识别器件`EG4S20BG256`；选`PROGRAM_SRAM`，加载本页位流并执行下载。等待软件明确报告完成，保持供电和线缆稳定。
3. 等待约30ms启动复位结束后，查看显示器有无信号提示/背光、是否出现稳定八色彩条；同时记录D0–D3常亮/闪烁模式。C11336应沿用C33的LED诊断逻辑，D2显示帧计数周期变化；记录实际状态，不推断PLL或Core锁定位于某物理灯的编号含义。
4. 若出现画面，记录显示器提示的分辨率/刷新率（若菜单提供）、首次出图时间及短时稳定状态。若仍无信号，记录屏幕文字和背光状态，以及D0–D3变化。
5. 等BitWriter确认任务结束后再换位流或关闭板卡。此测试只写SRAM；不执行Flash固化。此前C33失败位流保留，可由根代理安排复测或回退。

参考回退位流：[C32已确认基线](../../../player_video32_read_return/build/manual/AC201_player_video32_read_return.bit)。
