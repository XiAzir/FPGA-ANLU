# C35：受控显示链对照

用途：使用相同33/165MHz高频输出链，显示640×480/60Hz彩条，区分高频输出链与1080p15接收兼容性。

通过BitWriter PROGRAM_SRAM加载 `video35_640x480_60hz_33_165_bufg.bit`，JTAG沿用5MHz，供电/HDMI接线/显示器保持现场条件。等待10秒，数码管应固定 **00C11335**，观察“完整彩条 / 有背光无彩条 / 无信号”。

D0=PLL锁定，D1=板内HDMI核输入锁定，D2=帧活动周期闪烁，D3=启动等待完成。记录D3～D0与屏幕结果即可。位流输出固定彩条，1080p视频播放器在C34继续集成。

回退：加载包内 `video32_read_return_rollback.bit`，版本00C11332，TF素材保持即可。

最终FPGA内STA：

```
SWNS: 1.755ns, STNS: 0.000ns.
HWNS: 0.041ns, HTNS: 0.000ns.
```

外部显示器、线缆和电气接收尚待实测。彩条/PLL/串行字恢复模型及TD报告分别保留，硬件结果以本次反馈记录。

## 本次对照范围

像素/串行时钟沿用C36的33/165MHz；扫描为640×480、1000×550总时序、60Hz，采用自定义消隐。若出现彩条，可确认该接线下的高频输出链能传递这组栅格；1080p15的消隐参数与显示器接收情况继续分项核对。若仍无信号，接收兼容性和实际输出波形继续保留待查。

路由日志保留PHY-5014关于PLL fbclk[0]的提示；当前FEEDBK_PATH=VCO_PHASE_0、fbclk接0，采用内部VCO反馈。
