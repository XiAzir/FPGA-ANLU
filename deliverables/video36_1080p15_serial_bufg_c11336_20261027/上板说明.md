# C36：受控显示链对照

用途：保持C33的1920×1080/15Hz扫描，恢复与C32一致的串行全局时钟缓冲。

通过BitWriter PROGRAM_SRAM加载 `video36_1080p15_serial_bufg.bit`，JTAG沿用5MHz，供电/HDMI接线/显示器保持现场条件。等待10秒，数码管应固定 **00C11336**，观察“完整彩条 / 有背光无彩条 / 无信号”。

D0=PLL锁定，D1=板内HDMI核输入锁定，D2=帧活动周期闪烁，D3=启动等待完成。记录D3～D0与屏幕结果即可。位流输出固定彩条，1080p视频播放器在C34继续集成。

回退：加载包内 `video32_read_return_rollback.bit`，版本00C11332，TF素材保持即可。

最终FPGA内STA：

```
SWNS: 1.643ns, STNS: 0.000ns.
HWNS: 0.024ns, HTNS: 0.000ns.
```

外部显示器、线缆和电气接收尚待实测。彩条/PLL/串行字恢复模型及TD报告分别保留，硬件结果以本次反馈记录。
