# 给同学：真实音乐播放测试

文件准备状态：音乐已转换/校验，成功位流已备好。本包用于同学在原卡上正常复制文件后进行首轮真实音乐测试；音乐上板尚未验证。打包日期：2026-10-08 21:05:48（北京时间）。

## 文件放哪里

- card/TEST.WAV：复制到原TF卡根目录，替换原 TEST.WAV。
- firmware/packet_diag.bit：留在电脑上，用 BitWriter 下载到 FPGA；不要将位流当作卡上音乐文件。
- README.md、校验清单：操作说明，不需复制到TF卡。

只按文件方式替换TEST.WAV，Windows正常管理文件和FAT；不格式化、不改分区、不直接写物理扇区，不使用原厂sync_to_sd.py。保留原卡四张BMP和其他文件。

## 装卡步骤

1. 确认BitWriter没有正在下载后，断板电源，取下原TF卡放入电脑读卡器。确认资源管理器所选的是这张TF卡。
2. 将卡上原 TEST.WAV 复制到电脑备份；以后可恢复旧测试音频。不要把两个TEST.WAV放在同一根目录。
3. 从已完成的包内 card 文件夹复制 TEST.WAV 到TF卡根目录，选择替换。不要把整个card文件夹作为子目录放到卡里。不要复制firmware到TF卡；保留原四张BMP。
4. 等复制结束，确认文件名是 TEST.WAV（注意不是 TEST.WAV.wav）、大小与包内清单一致，然后安全弹出。
5. 板卡断电时插回TF卡，上电，沿用原供电和HDMI接线。

## 下载与观察

1. 将 firmware/packet_diag.bit 复制到电脑纯英文目录，例如 E:/bit/packet_diag.bit 或 D:/bit/packet_diag.bit（选该电脑已有硬盘盘符）。不要放在中文/空格路径；该电脑无需有开发工程或重新编译。
2. BitWriter 按既有 PROGRAM_SRAM 流程 Add 这份位流并下载，等明确成功后再操作按键。断电会丢失SRAM配置，因此此次重新上电需要重载。
3. 等启动完成，默认应播放新音乐并正常显示原图片。先听完两次约60秒片段循环；循环回开头是预期，但不应有沙沙/错音或持续异常。
4. 短按KEY0手动切图；短按KEY1开关自动轮播，检查图片正确且音乐不中断。这里不需要长按KEY1；长按切到内部音阶，不会播放新音乐。
5. 把音乐是否清楚、循环是否正常、切图是否影响声音反馈给用户。有异常时拍到画面/声音/数码管，并注明操作。当前只做约60秒真实音乐首轮测试，不等于长时稳定性验证。
